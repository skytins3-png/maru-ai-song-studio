# MARU RADIO · Suno 30인 보컬 원본 중심 방송 (TTS 미사용)

## 왜 보컬 원곡을 연결하는가
사용자가 원하는 핵심은 각 AI 가수의 **서로 다른 음색을 가진 실제 Suno 원곡**을 방송 캐릭터와 정확히 연결하는 것이다. 운영체제 TTS의 이름·피치를 바꾸는 것은 그 AI 가수의 고유 보컬이라고 볼 수 없으므로 이번 미리보기 재생 경로에서 TTS 호출을 제거했다.

## Suno 공식 기능
- [Style Persona](https://help.suno.com/en/articles/3484161): 원곡에서 보컬+스타일 특성을 저장해 다음 신곡의 일관성에 활용. Persona가 실재하는 가수의 신원을 증명하거나 100% 동일한 음색을 보증하지는 않는다. 비공개로 생성 권장.
- [Get Stems](https://help.suno.com/en/articles/13925185): 소유/사용 권한이 있는 노래 → (...) → Get Stems → 음성 분리(보컬·나머지). Premier에서는 최신 고급 분리도 제공되며 옵션에 따라 크레딧이 사용될 수 있다.
- [Download](https://help.suno.com/en/articles/13926081): 소유·권리 확인된 원곡 MP3/WAV 및 생성된 분리본 다운로드 가능. 다운로드 개수/플랜 제한을 사전 확인할 것.
- [Voices](https://help.suno.com/en/articles/11362369): 본인의 실제 목소리를 검증하여 만드는 기능이다. 생성된 가상의 Suno 가수 보컬 분리본을 무단 제삼자 음성 모델로 변환하는 기능과 혼동하지 말 것.
- [Commercial rights](https://help.suno.com/en/articles/9601665): 유료 플랜에서 생성한 곡의 상업적 사용 허가와 저작권 법적 보호는 별개의 문제이며, 실제 사용권/제3자 저작물 권리 확인 필요.

## 실제 사용 순서
1. Suno에서 권리 보유한 각 가수의 **실제 원곡**을 MP3/WAV로 저장한다.
2. 필요한 경우 원곡에서 **Get Stems**로 노래 보컬을 분리한다.
3. MARU RADIO SHOW 웹 화면의 ①에서 원곡 파일을 추가한 뒤, 곡 목록에 생긴 **가수 ID 선택**에서 해당 보컬 후보를 지정한다. 파일명에 해당 이름이 단독 포함되면 자동 후보로 지정하되, 실제 가수 확인 책임은 편성자에게 있다.
4. ② **Suno 30명 보컬·방송 멘트 등록**에서 동일한 가수 ID를 골라 보컬 분리본을 등록하고 미리 들어 음색을 확인한다.
5. 노래가 재생되면 원곡의 기존 보컬이 나오고, 화면에는 그 ID의 가수명/무대 이미지(승인된 개인 미디어가 있을 때)가 나온다. 미확정 얼굴은 가상 도형/일러스트 대체 화면으로 표시한다.
6. 초대석 진행은 **정확히 해당 문장을 말한 파일**을 각 화자와 대본 문장에 연결해야만 해당 순간에 음성이 재생된다. 예를 들어 아환의 "안녕하세요" 원본을 업로드했다고 해서 모든 노래 제목을 자동으로 말하게 하는 건 아니다.
7. 녹음 파일이 없는 멘트는 **자막만** 표시한다. 어떤 경우에도 음성합성(TTS)으로 자동 대체하지 않는다. 원본을 받아 복제·학습하는 기능도 없다.

## 데이터/권리 및 운영 한계
- 30명의 이름/ID는 현행 `vocal-studio/artists.json`의 정식 **후보 등록부**를 참조하며, `production-status.json`의 완료·승인 수는 0이다. 다른 이전 시안에서 이름만 붙은 30인 포스터와 서로 다른 목록이 있을 수 있어 이미지에 잘못 붙은 이름으로 자동 매칭하지 않는다.
- Suno 로그인/인증 정보, 사적 노래 라이브러리, 음원을 읽는 원격 API 연결은 현재 제공되지 않는다. 자동 수집·무단 다운로드 불가. 사용자가 원하는 파일을 직접 내려받아 브라우저에서 선택하는 방식이다.
- 노래를 다운로드하거나 Stem을 분리한다고 **자유로운 대화용 음성 모델**이 자동 생성되는 것은 아니다. 스피치용 녹음이 별도로 없으면 라디오 진행은 자막과 음악으로만 이루어진다.
- 등록 파일/분리본·녹음 클립은 현재 브라우저의 Object URL로만 사용하고 업로드하거나 자동 공개/저장하지 않는다. 종료 시 연결 해제, 원본 다운로드 파일은 삭제되지 않는다.
- 보컬과 인물 얼굴·목소리, 제3자 권리, 상표, 방송용 라이선스 확인이 끝나기 전에는 정식 가수 제작 완료를 주장하지 않는다.
- BIGO 오디오 LIVE 청취자 실송출, 실제 입술 동기화, 무인 방송 연속성은 별도 검증이 필요하다.
