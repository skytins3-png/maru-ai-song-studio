## 실제 영상으로 만들기 위한 다음 조건
1. 각 캐릭터 영상은 사용 허락이 확인된 원본 영상 클립이 있어야 합니다. **일러스트를 움직이는 AI 입술 동기화, 노래 제스처, 자동 생성 라이브 영상은 이 PR에서 구현하지 않았습니다.**
2. 원본 Suno 음원을 연결해도 곡에 입술을 자동으로 맞추는 기능은 없습니다. 유저가 지정한 배경/캐릭터 영상만 반복해서 화면에 보입니다.
3. 현재 구현은 **웹 브라우저 로컬 영상 리허설**입니다. Android 앱 내부 화면의 BIGO 비디오/오디오 LIVE 송출은 별도 연동·권한 및 실청취 검증이 필요합니다.
4. 캐릭터는 실존 방송인 또는 가수의 얼굴/음성을 모사하지 않고 완전한 가상 설정입니다. Suno 30인 가수 제작 및 승인 수와 혼동해서는 안 됩니다.
5. 청취자가 올린 이미지/영상은 직접 자동 재생하지 않습니다. 서버 측 격리 검사·권리 승인·발행 파이프라인을 통과한 뒤에만 별도 연결할 수 있습니다.

## 실제 사용 방법
1. [MARU RADIO SHOW](../vocal-studio/radio-show.html)을 열어 화면 **③ 영상 무대·초대석**을 확인합니다.
2. **무대 보기**, **초대석 보기**, **진행자 보기** 버튼으로 세 화면을 전환합니다. **세로 9:16 / 정사각 1:1**을 고릅니다.
3. 캐릭터 선택 → 본인이 권리 보유한 이미지/동영상 확인 체크 → 파일 선택으로 해당 캐릭터 화면을 등록합니다.
4. 섹션 ①에서 본인 Suno 원곡을 선택하고 섹션 ②의 권리 확인 후 라디오를 시작합니다. 곡 소개→노래→대화 순으로 화면이 자동 전환됩니다.
5. 파일 영상은 서버로 전송되지 않으며 페이지를 닫으면 다시 등록해야 합니다.
