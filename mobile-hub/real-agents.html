실제 AI 연결 조건

현재 GitHub Copilot CLI가 GitHub Actions의 임시 토큰으로 실제 AI 보고서를 생성하도록 연결됐어. 새 OpenAI API 키가 없어도 별도의 실제 모델 호출이 가능해. 모델 사용량을 보호하기 위해 한 번 실행할 때 최대 3명의 담당자만 AI 분석하고, 매일 3명씩 순환해. 나머지 15명은 ‘모델 순환 대기’로 표시해.

기존 OpenAI API 키가 유효하게 연결되면 그 모델도 사용할 수 있어. GitHub Copilot 모델 이용에는 계정의 구독·사용량 제한 또는 요금이 적용될 수 있어. 비밀번호와 키는 공개 GitHub 파일이나 채팅에 올리지 마.
