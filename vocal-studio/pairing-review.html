휴대폰에서 평가한 비공개 JSON을 불러와 두 곡씩 묶인 가수 후보의 제작 준비 상태를 확인합니다.

가수 30명 제작 완료 화면이 아닙니다.

원곡 105개는 30명의 고유 보컬과 같지 않습니다. 개인의 청음 점수와 두 곡 연결 결과는 오디션 제작 순서를 정하는 참고일 뿐, 실제 Persona 생성·법적 검토·BIGO 실송출 승인과 구분합니다.

1. 비공개 선별 결과 가져오기

개별 음원 청음 기록 화면 또는 이전에 받은 105곡 오프라인 ZIP 청음 화면에서 「청음·보컬 매칭 JSON 저장」으로 만든 파일을 선택합니다.

JSON 파일은 이 브라우저에서만 읽으며 서버나 공개 GitHub로 업로드하지 않습니다.

2. 30명 제작 준비 현황

청음 JSON 미선택

동일 바이트 파일이 아니라도 MP3·M4A처럼 다른 인코딩으로 보이는 음원은 독립된 두 곡으로 인정하지 않습니다. 별도 원본 음원 청취와 검증이 필요합니다.

합격 표시가 뜨더라도 목소리 고정, 동일 가수 검증, 공연권·상표 확인 및 실제 송출까지 진행해야 정식 제작 완료입니다.
