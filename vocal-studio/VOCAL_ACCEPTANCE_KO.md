# MARU STUDIO — 전문 가수 30명 정식 등록 기준

## 현재 진척: 합격한 가수 0/30명
이 저장소의 `vocal-studio/artists.json`은 가수 프로필 초안 및 Suno 프롬프트만 담습니다. **이름만 등록하거나 프롬프트만 완성했다고 가수로 인정하지 않습니다.** 
오직 `production-status.json`에서 확인된 목소리와 증빙을 기준으로 제작 완료 여부를 판단합니다.

## 1명당 의무 시험
1. 실제 서로 다른 노래 2곡 이상, 순수 보컬 식별이 가능한 샘플 + 음원 마스터 확인 (한 곡 파일의 단순 복사/재인코딩은 불합격).
2. 두 곡을 서로 비교하여 동일한 고유 보컬 캐릭터가 유지되는지 청취 검사. 음정 안정성·발음·감정 표현·장르 적합도·음질 각각 1~5점; 항목별 4점 이상이며 합계 22/25점 이상.
3. 실제 가수·모델·방송인의 무단 음성 복제/샘플링 금지. 단순 예명 변경만으로 타인의 음성을 상업적으로 이용하지 않음.
4. 방송·판매 권리, 소스 라이선스, 배포 조건과 제작자 기록 보관. 예명 및 상표 동명·유사 선행 조사, 최종 사용 가능 판단 기록.
5. 최종 방송용 음원을 모바일에서 재생·곡 전환·오디오 왜곡·클리핑·청취자 송출 확인. 미검증이면 approved=false.

## 합창 그룹 승인
- 여성 3명 각 독립 목소리 + 3성부 혼합 및 동시 발음·위상 충돌 점검.
- 남성 7명 각 독립 목소리 + 7성부 구성/합창 재현성, 저음·고음 밸런스 점검.
- 그룹 합창 테스트를 통과하지 못하면 정규 그룹 방송 확정 금지.

## 정식 완료 판정
`production-status.json`의 `artists` 30개가 각각 `approved: true`이고,
실제 마스터 파일·음성 고유성·두 곡 일관성·권리·예명 조사가 모두 검증됐으며,
여성 3인조·남성 7인조 화음과 BIGO 청취자 수신 테스트가 모두 통과해야 `complete:true`로 바꿀 수 있습니다.
실제 검증 없이 숫자나 bool만 임의 변경하는 것은 금지합니다.

## 현재 미구현 / 외부 의존
Suno 노래 생성, 동일 AI 보컬 Persona 제작, 법률조사 및 방송 전송 검증은 별도 서비스와 실제 음원 및 권한이 필요합니다. GitHub 코드만 수정했다고 가수 30명이 노래하는 것은 아닙니다.

## 60곡 제작실 워크플로
1. `make.html`에서 후보 선택 → 테스트 A의 제목·스타일·가사 복사 → Suno 공식 Create 화면에서 직접 생성.
2. 생성된 노래의 크레딧과 이용권한 확인 후 원본 보관. 마스터 선정을 위해 후보들 A/B 음색을 비교 청취.
3. 직접 권리를 가진 Suno 결과물로 Style Persona를 만들어 두 번째 테스트곡을 생성하고 목소리 안정성을 확인.
4. `audition.html`에서 원본을 등록해 PCM 음질 검증(클리핑, RMS 등) 및 심사, 권리 확인.
5. 실제 BIGO 시청자용 음질 테스트와 예명 선행 조사까지 끝난 사람만 별도 승인.
