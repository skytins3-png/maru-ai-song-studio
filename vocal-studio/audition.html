🎙️ 전문 보컬 오디션

이름만 등록하지 않습니다. 실제 노래 두 곡과 심사 결과가 있어야 통과합니다.

현재 정식 제작 완료 가수: 확인 중

이 오디션은 휴대폰 안에서 심사용 음악과 평가를 관리합니다. 합격은 개인 평가 기록이며 실제 음성 모델 제작, 가수 데뷔, 법적 사용권, BIGO 방송 송출을 증명하지 않습니다.

실제 가수·BIGO 방송인의 목소리를 허락 없이 복제하거나 다른 예명으로 방송하지 않습니다.

1. 심사할 후보 선택

여성 3인조 3명 · 남성 7인조 7명 · 여성 솔로 10명 · 남성 솔로 10명. 모든 후보는 기본 미승인 상태입니다.

후보별 Suno 스타일 / 음색 참고

2. 실제 노래 두 곡 올리기

두 곡은 가수가 서로 다른 노래를 부른 독립적인 음원이어야 합니다. 같은 곡 복제·이름 바꾸기는 통과하지 못합니다. 로컬에만 저장하고 서버에 자동 업로드하지 않습니다.

음원 미등록
음원 미등록

최대 25MB/파일, 45초 이상. 저장 공간 부족이나 코덱 미지원 시 등록에 실패할 수 있습니다. 음원의 독립성은 SHA-256으로 검사하지만 보컬 동일 여부는 사람이 실제 청취해 판단해야 합니다.

3. 가창력 6가지 평가

각 항목 최소 4점, 총점 26/30점 이상이어야 합니다.

4. 필수 검증

아직 심사 전

심사 결과만으로 정식 가수 등록 수가 올라가지는 않습니다. 방송 전 음원의 실제 사용권과 청취자 측 송출 검증이 추가로 필요합니다.
