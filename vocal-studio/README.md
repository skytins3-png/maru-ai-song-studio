# MARU STUDIO · 30 vocal concept candidates (NOT finished singers)
- 가수 등록 완료는 0명. 현재 30개 이름과 스타일만 존재하며 고유 음성 모델/노래는 없음. 후보 명단을 완성 가수로 표기하지 않음.
- 공개 진입점: `/vocal-studio/`. 기존 MARU 본 앱·MUSIC SHARE·MARU RADIO 코드와 격리.
- `artists.json`: 한국어 예명 30개, 여성 3인조 3명 / 남성 7인조 7명 / 여성 솔로 10명 / 남성 솔로 10명.
- 30명에게 서로 다른 음색, 음역, 창법, 반주 악기, 언어, 합창 파트와 Suno Styles(<1000자) 제공.
- Browser IndexedDB에 개별 가수 MP3/WAV/M4A 등 음원 등록. 오디션 및 편성 목록 연속재생. 음원 서버 업로드 없음.
- 권리 확인 체크 이후 로컬 음원 등록. 음성 모델 생성·Suno 연결·BIGO 직접 송출·무인 생방송 자동화 구현 아님.
- Suno Voices는 자기 목소리 검증만 허용하며, 타인 목소리·방송 녹음으로 음성 모델을 만들면 안 됨.
- 가상 가수 음색/스타일의 지속성을 추구할 때는 권리 확보된 독창적 음원에서 Style Persona를 만들어 사용.
- 예명/상표 중복조사 및 법적 검토는 미완료. 이름을 실제 무명 가수나 연예인과 중복되지 않는다고 보증하지 않음.

검증: artists.length === 30, 이름 및 ID 중복 없음, 3/7/10/10 분류, 스타일 프롬프트 1000자 미만, JS 구문 검사. 브라우저·Suno·BIGO 실제 운영은 사용자 기기에서 별도 실증 필요.

## 보컬 오디션 구현
- `audition.html`: 가수 후보 30명을 실제 노래 파일 2곡으로 오디션하는 독립 모바일 화면. 음원은 사용자가 선택한 경우 이 기기 IndexedDB에만 저장됨.
- `audition-policy.js`: SHA-256 파일 중복방지·곡당 45초 조건, 가창력 6분야 4점 이상/총점 26점 이상, 청취·음성모사 금지·방송권리·예명 사전 검토 등 필수 확인 조건.
- `audition.js`: MP3/WAV/M4A 등 로컬 파일 등록, 가수별 심사 및 결과 내보내기.
- **경고:** 로컬 자가 심사 합격 ≠ 공식 가수 제작 완료. 중앙 `production-status.json` 0/30과는 연동하지 않음. 법률 전문 검토·전문 음악 QA·BIGO 실송출은 아직 수행하지 않음.
- `node --test tests/vocal-audition.test.cjs`에서 통과/실패 기준 검사.
