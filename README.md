# MARU WORLD MUSIC MAKER V0.4.0 MELODY SCORE

음악 이론을 몰라도 분위기, 지역, 악기를 골라 가사와 음악 설계를 만들 수 있는 설치형 웹앱(PWA)입니다.

## 현재 기능

- 8개 문화권 전통악기와 현대악기·오케스트라 분류
- 피아노, 기타, 베이스, 드럼, 신시사이저, 색소폰, 808 베이스 등 현대악기 12종
- 이야기 주제에 따른 가사·제목 자동 구성(휴가·사랑·이별·치유·축하·댄스·희망)
- 사랑·약속·추억 등 핵심 단어 선택과 직접 입력
- 반복해서 기억되는 사용자 지정 후렴 훅
- 보통/풍성한 가사 밀도와 후렴 2~4회 선택
- 4분·4분 30초 곡용 3절, 간주, 아웃트로 후렴 확장
- 조성·박자·BPM에 맞춘 후렴 8마디 멜로디 자동 생성
- 오선지에 음표·코드·가사 표시 및 음표 위치 재생
- 악보 인쇄·PDF 저장과 SVG 악보 다운로드
- 장르, BPM, 박자, 조성, 보컬, 악기와 편곡 방향 자동 분석
- 악기별 합성 음색 미리듣기
- 발라드·댄스·트로트·록·퓨전에 따라 리듬과 음 진행이 달라지는 반주 미리듣기
- 분위기에 맞춘 BPM 및 4/4박자 자동 설정
- 고정 문구 끼워 넣기 대신 이야기 유형별 가사 작성
- 보컬, 언어, 장르, 곡 길이 선택
- 가사와 스타일 복사
- 최대 30곡 브라우저 임시 저장
- 가사와 음악 설계 TXT 파일 다운로드
- 이전 버전 캐시 자동 삭제 및 새 파일 강제 갱신
- `가야금과 대금이`처럼 한국어 악기 조사 자동 교정
- 휴대폰 홈 화면 설치 및 오프라인 실행

## 실행

로컬 서버에서 폴더를 열어야 설치와 오프라인 기능이 정상 작동합니다.

```bash
npx serve .
```

첫 버전의 악기 소리는 Web Audio 합성 음색입니다. 실제 악기 샘플, 고품질 반주 파일 저장, AI 보컬 완성곡은 후속 개선 항목입니다.
