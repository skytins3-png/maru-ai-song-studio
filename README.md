

## V0.20.0 — 간편 분석·보컬 또렷·컴팩트 악보
- 분석 뒤 한 곳에서 원곡 / 추출 멜로디 / 전체 편곡 / 정지를 조작합니다.
- BPM 신뢰도가 낮으면 구간별 결과를 군집화해 후보 BPM 버튼을 보여주고, 선택한 BPM으로 악보·코드를 다시 분석합니다.
- 완성 음원에서 정확한 악기명을 단정하지 않고, 저역·타격·지속 화음의 역할 힌트와 장르를 결합해 편곡 악기를 추천합니다.
- 자동 편곡은 역할별 자동 음량 균형과 보컬 또렷 모드를 기본으로 사용합니다.
- 마이크로 녹음한 원곡을 편곡과 시간 동기화해 작게 함께 들을 수 있습니다. 보컬 분리 기능은 아니며 원곡 전체가 섞입니다.
- 악보는 한 줄 4마디를 화면 폭에 맞추고 시스템 세로 간격을 줄였습니다. 세부 편집 UI는 기본 숨김입니다.
- 악기/반주/가사/보컬/저장함 카드는 접기·펼치기를 지원하고 기본적으로 접혀 있습니다.
# V0.20.0 · 전체 편곡 버튼 복구 + 멜로디 채보 강화

- V0.19.7에서 저장 함수 10개가 빠져 초기화가 `save is not defined`에서 중단되던 회귀 오류를 복구했습니다. 이 오류 때문에 구간별 반주 버튼은 동작하지만 그 뒤에 연결되는 `선택 마디 듣기`와 `전체 편곡 듣기` 등은 클릭 핸들러가 등록되지 않았습니다.
- 자동 채보 멜로디는 한 박자를 4등분한 8분음표 기준으로 한 슬롯의 복수 피치 후보를 비교하고, 연속 음정과 신뢰도를 함께 사용합니다. 낮은 신뢰도 표본만 검출 조성으로 보정합니다.
- 마디별 코드는 24개 메이저/마이너 코드를 무제한 선택하지 않고 검출된 조성의 주요 다이어토닉 코드 후보 안에서 고릅니다.
- 분석 추천 악기는 실제 악기 분리 감지가 아니라 장르·에너지에 따른 편곡 역할 추천입니다. 적용 시 실제 선택 Set에 모두 들어갑니다.
- 저장/불러오기/TXT/Suno 복사/백업 기능도 함께 복구했습니다.

# V0.19.7 · 실제 채보 정렬 + 마디별 코드 + 전체 편곡 재생 복구

이번 버전은 사용자가 실제 테스트에서 “악보가 원곡과 맞지 않고 전체 편곡 듣기가 시작되지 않는다”고 보고한 문제를 기준으로 수정했습니다.

- 분석 완료 즉시 실제 음표 악보까지 자동 생성
- BPM만 맞추는 것이 아니라 온셋을 이용해 박자 시작점(beat-grid phase)을 보정
- 주멜로디 채보용 신호를 별도 12 kHz 중앙/중역 강조 경로로 만들어 저역·타악기 간섭 감소
- 마디별 코드(메이저/마이너)를 실제 음원 크로마에서 추정하고 악보 위 코드와 편곡 반주에 동일 사용
- 자동 채보곡의 아래 `▶ 전체 편곡 듣기`도 분석 악보가 없으면 자동으로 생성한 뒤 재생
- SoundFont 로드가 끝난 뒤 AudioContext를 다시 resume하고 첫 마디는 setTimeout 없이 즉시 예약
- 재생 상태를 분석 적용 상태 영역에 표시
- 실제 녹음 곡에서는 보컬과 반주가 섞여 있으므로 채보를 100% 원곡 악보라고 보장하지 않음

# V0.19.7 · 분석 직후 자동 적용 + 스타일 중복 제거 + 정확한 길이

- 분석 완료 즉시 BPM/박자/조성/스타일/추천 악기를 실제 설정에 자동 적용합니다.
- `✨ 분석 스타일 다시 적용`은 사용자가 설정을 바꾼 뒤 분석값으로 복원하는 버튼입니다.
- 분석 스타일은 한 번만 표시합니다.
- 5:31 같은 길이는 `약 5:31`처럼 표시하며 6분으로 거칠게 반올림하지 않습니다.
- 길이 선택에 5분/5분30초/6분을 추가했습니다.
- 분석 신뢰도는 실제 검증 결과를 그대로 표시하며 억지로 100%로 올리지 않습니다.

# V0.19.7 · 분석값-스타일-악기-악보 완전 동기화

- V0.19.4에서 발견된 핵심 버그 수정: `updateScoreMode()`가 분석으로 적용한 BPM/박자/조성을 장르 기본값으로 다시 덮어쓰던 문제를 제거했습니다.
- 예: 분석값이 `125 BPM · F Major`이면 악보도 반드시 `125 BPM · F Major`를 사용합니다. 더 이상 `126 BPM · G Major` 같은 기본값으로 되돌아가지 않습니다.
- `✨ 이 스타일 바로 적용`은 분석 BPM·박자·조성·스타일·추천 악기를 한 번에 실제 설정으로 적용합니다.
- 분석 스타일은 textarea뿐 아니라 화면의 읽기 가능한 미리보기에도 표시되어 빈 것처럼 보이지 않습니다.
- 악보 생성 직후 `분석값 일치 ✓` 상태를 표시해 실제 동기화 여부를 확인할 수 있습니다.
- 악보 메타의 길이는 마디 역산값이 아니라 실제 녹음 길이를 표시합니다.

- BPM을 전체 곡 + 최대 7개 구간에서 반복 추정해 일치도를 검증합니다.
- 조성도 전체 + 여러 구간 후보를 투표해 상대조/오판 가능성을 낮춥니다.
- 모든 검증이 강하게 일치할 때만 100% 신뢰도를 표시하며, 억지로 100%를 만들지 않습니다.
- 기존 120마디 상한을 제거해 녹음 전체 길이를 끝까지 채보합니다.
- 분석 스타일 바로 적용 시 추천 악기까지 기존 선택과 관계없이 실제 선택합니다.

# V0.18.4 · 모던 팝 실제 편곡 재생 강화

- 96 BPM / 4/4 / G Major 모던 팝에서 구간별 코드 진행과 악기 역할을 실제 재생에 반영합니다.
- Verse: I–V–vi–IV 기반, 피아노 아르페지오·절제된 기타·루트/5도 베이스·가벼운 킥/스네어/하이햇.
- Pre-Chorus: ii–IV–I–V 진행과 상승 아르페지오/현악 라인/드럼 빌드로 긴장을 높입니다.
- Chorus: I–V–vi–IV, 넓은 피아노 코드·8분 기타 스트럼·움직이는 베이스·킥/스네어/하이햇·현악 2성 화음.
- Bridge: vi–IV–I–V로 대비하고 드럼/반주 밀도를 낮춥니다.
- Final Chorus: 현악을 한 옥타브 올리고 추가 컬러톤을 넣어 음역·화음을 확장합니다.
- 드럼 세트는 기존 순환 샘플이 아니라 Kick(36) / Snare(38) / Closed Hat(42) / Crash(49) / Tom(45/47)을 직접 지정해 연주합니다.
- 50% 혼합은 선택한 지역/오케스트라 악기와 현대악기의 합주 에너지 비중으로 계산합니다.
- V0.18.2의 보잉 표현과 V0.18.1의 귀 보정은 그대로 유지합니다.

> 앱은 실제 가창을 합성하지 않으므로 피아노가 보컬 멜로디 가이드 역할을 합니다. 최종 보컬은 스타일 프롬프트 또는 별도 녹음 단계에서 사용합니다.

# V0.18.3 · 실제 스타일 조건 기반 구간별 편곡 재생

- `전체 편곡 듣기`가 첫 악기 하나만 재생하던 문제 수정: 선택 악기 전체를 역할별로 합주합니다.
- Verse / Pre-Chorus / Chorus / Bridge / Final Chorus의 밀도·다이내믹·현악 화음·드럼 패턴을 다르게 재생합니다.

- 피아노 계열 한 악기는 보컬 멜로디 가이드로 전면에 두고 나머지는 반주 역할을 맡습니다.
- 수동으로 악기를 고른 경우 `노래 설계`에서 자동 악기 선택이 덮어쓰지 않도록 수정했습니다.
- 오케스트라 지역에서는 잘못된 `전통악기 비율` 문구를 `오케스트라 악기 비율`로 표시합니다.
- V0.18.2 보잉 표현 및 이전 음량 보정은 모두 포함합니다.

# MARU WORLD MUSIC MAKER V0.18.3 — 활 미는/당기는 보잉 표현

V0.18.3는 활을 사용하는 현악기의 정적인 지속음을 개선합니다.

- 적용: 해금, 얼후, 바이올린, 첼로, 바이올린 섹션, 비올라, 첼로 섹션, 콘트라베이스
- 미는 활 → 힘이 붙는 구간 → 중앙의 자연스러운 활 바꿈 → 당기는 활의 흐름을 음량 엔벌로프로 표현
- 악기별 자연스러운 비브라토 속도/폭 적용
- Sfumato 엔진에 AudioBufferSource detune LFO 지원을 추가해 pitch vibrato가 실제 샘플에 적용됨
- SoundFont에 원래 vibLfoToPitch/freqVibLFO/delayVibLFO가 들어 있는 경우도 재생 엔진이 이를 반영할 수 있도록 개선
- 원음 1음에서 활 악기는 약 2.15초 유지해 왕복 보잉의 움직임을 쉽게 비교
- 탄푸라, 가야금, 고쟁, 기타류처럼 활을 사용하지 않는 현악기는 보잉 처리에서 제외

> 샘플 자체가 실제 해금/얼후 녹음이 아닌 경우에는 표현은 개선되지만 악기 정체성이 100% 실제 녹음과 같아지지는 않습니다.

# MARU WORLD MUSIC MAKER V0.17.9 BALANCED CHARACTER AUDIO

V0.17.9은 V0.17.7의 이중 청음 보정을 제거하고, GeneralUser.sf2의 대표 샘플을 다시 분석해 52개 악기를 한 번의 정적 평준화 표로 맞춘 버전입니다.

## V0.17.9 핵심 변경
- 대표 샘플 RMS 계산 기준으로 52개 `SAMPLE_OUTPUT_GAINS`를 전면 재작성했습니다.
- 청음 전용 `AUDITION_NORMALIZE`를 제거해 이중 보정으로 다시 차이가 벌어지는 문제를 없앴습니다.
- 계산 기준 대표 출력 편차를 약 2.3 dB 범위로 좁혔습니다(실제 스피커 체감은 음역/주파수에 따라 달라질 수 있음).
- 기본 전체 음량은 160%, 조절 범위는 70~220%로 변경했습니다.
- 가야금과 고쟁의 근사 프리셋을 `Koto`로 변경했습니다. Dulcimer는 고쟁처럼 뜯는 지터보다 타현 악기에 가까워 제외했습니다.
- 대체 음원에만 약한 EQ/캐릭터 레이어를 적용했습니다. 대금·네이·반수리 등은 숨결, 해금·얼후는 미세한 활 마찰, 지터/루트류는 짧은 플럭 어택을 아주 작게 보강합니다.
- 직접 대응 샘플은 가능한 원래 SoundFont 음색을 유지합니다.
- 리미터를 더 투명하게 조정해 큰 악기만 과도하게 눌리는 현상을 줄였습니다.

## 한계
GeneralUser GS 안에 실제 장구·타블라·탄푸라·다르부카·젬베 등의 전용 녹음은 없습니다. 이 악기들은 현재 가진 SoundFont만으로 100% 실제 고유음이 될 수 없습니다. 또한 현재 `sfumato.js`는 GeneralUser GS가 많이 사용하는 SoundFont modulator를 완전 구현하지 않으므로, 다음 큰 단계는 standards-compliant SoundFont 엔진으로 교체하는 것입니다.

# MARU WORLD MUSIC MAKER V0.17.9 AUDIBLE LEVEL + SOURCE AUDIT

V0.17.9은 실제 GitHub Pages 배포본 V0.17.6을 다시 분석해, 악기 확인 음량을 샘플 RMS 기준으로 평준화하고 원본 SoundFont 프리셋을 화면에 공개한 버전입니다.

## 이번 핵심
- 52개 악기 청음 레벨을 실제 GeneralUser GS 1.471 샘플/감쇠값 기준으로 재분석했습니다.
- 기본 전체 음량을 170%로 올리고, 청음 전용 개별 정규화 값을 추가했습니다.
- 리미터는 큰 소리의 피크만 억제하도록 문턱을 높였습니다.
- `🔊 원음 1음` 버튼을 추가해 멜로디 없이 대표 한 음만 들을 수 있습니다.
- `🎼 특징 연주`는 기존 악기군별 확인 패턴을 유지합니다.
- 각 카드에 `원본 SF2: Flute / Koto / Violin ...`을 표시해 대체 음원을 숨기지 않습니다.
- '실제 샘플/좋은 근사' 표현을 더 엄격한 `직접 대응 / 대체 음원 / 전용 음원 필요`로 변경했습니다.
- 고쟁(Dulcimer)은 연주 방식 차이가 커서 `전용 음원 필요`로 재분류했습니다.
- 바이올린 섹션, 첼로 섹션, 합창 패드는 범용 섹션/합창 프리셋이므로 `대체 음원`으로 재분류했습니다.

## 중요한 한계
현재 포함된 GeneralUser GS 1.471은 범용 GM/GS SoundFont입니다. 가야금, 대금, 해금, 장구, 얼후, 고쟁, 비파, 디즈, 타블라, 탄푸라, 우드, 카눈, 네이, 다르부카, 코라, 젬베, 발라폰, 차랑고, 케나, 봄보 등의 전용 녹음이 모두 들어 있는 전통악기 전용 라이브러리가 아닙니다. 따라서 이 악기들은 볼륨을 고쳐도 100% 고유 음색이 될 수 없습니다.

또한 현재 브라우저 엔진 `sfumato.js`는 SoundFont의 generator 일부는 적용하지만, GeneralUser가 사용하는 모든 SF2 modulators를 완전하게 처리하는 엔진은 아닙니다. 전통악기 고유음을 해결하려면 다음 단계에서 전용 샘플을 추가하고, 범용 GM 악기의 정확도를 더 높이려면 보다 완전한 SoundFont 엔진으로 교체하는 것이 맞습니다.

V0.17.9은 V0.17.5 배포본을 기준으로 실제 청음에서 드러난 낮은 체감 음량과 획일적인 악기 테스트 멜로디를 개선한 버전입니다.

- SoundFont 재생 엔진이 `initialAttenuation`을 무시하던 문제를 수정했습니다. 원래 SoundFont에 저장된 악기/레이어별 감쇠값을 실제 출력에 반영해 과도하게 크거나 뭉개지는 샘플을 줄였습니다.
- `initialFilterFc`를 Web Audio 저역통과 필터에 반영해 같은 원본 샘플을 공유하는 프리셋도 SoundFont가 의도한 밝기 차이를 더 잘 냅니다. `coarseTune`도 실제 피치에 반영합니다.
- velocity(연주 세기)와 최종 출력 gain을 분리했습니다. `pp~ff`나 악보의 세기 변화는 velocity가 담당하고, 52개 악기의 기본 음량 차이는 별도의 출력 gain 표로 보정합니다.
- 전체 샘플 버스를 DynamicsCompressor에 연결해 여러 악기를 동시에 재생할 때 순간 피크가 과도하게 튀는 현상을 줄였습니다.
- 화면에 `전체 악기 음량` 슬라이더(50~180%, 기본 115%)를 추가하고 브라우저에 마지막 값을 기억합니다.
- 각 악기 카드에 `실제 샘플 / 좋은 근사 / 전용 샘플 권장`을 표시해 GeneralUser GS가 실제 전통악기 음원을 제공하는지 바로 알 수 있습니다.
- 남미 `봄보`는 Power Kick/Tom 근사 대신 GeneralUser GS의 GM `Surdo Muted/Open` 저음북을 사용하도록 변경했습니다.
- V0.17.4의 velocity-range 레이어 필터링, 런타임 SF2 캐시, 저장함/백업/PWA 수정은 그대로 유지합니다.

검토 한계: GeneralUser GS 안에 실제 가야금·장구·타블라·탄푸라·다르부카·젬베 등의 전용 녹음 샘플은 없습니다. 이 항목은 코드 보정만으로 원악기와 동일하게 만들 수 없으며, 앱에서 `전용 샘플 권장` 또는 `좋은 근사`로 명시합니다.

# MARU WORLD MUSIC MAKER V0.17.4 FULL AUDIO AUDIT FIX

V0.17.4는 V0.17.3 전체 배포본을 다시 검사해 SoundFont 재생 엔진의 핵심 문제를 수정했습니다.

- Sfumato가 SoundFont의 velocity range를 무시해 여러 세기 레이어를 한 음에 동시에 겹쳐 재생하던 문제를 수정했습니다. 예를 들어 Stereo Grand 피아노는 기존에 한 음에서 8개 velocity 레이어가 동시에 켜질 수 있었고, Timpani는 최대 20개 레이어가 겹칠 수 있었습니다. 이제 현재 velocity에 맞는 레이어만 재생합니다.
- pp·p·mp·mf·f·ff가 사실상 두 단계 음량으로 압축되던 계산을 연속적인 세기 곡선으로 변경했습니다.
- 실제 레이어 필터링 후 지나치게 작아지지 않도록 악기 단독 미리듣기와 조합 반주의 기본 세기를 소폭 보정했습니다.
- SoundFont 첫 다운로드가 일시적으로 실패하면 새로고침 전까지 계속 실패하던 Promise 고정 문제를 수정해 다음 시도에서 다시 받을 수 있게 했습니다.
- 31MB `GeneralUser.sf2`를 서비스워커 설치 단계에서 강제로 미리 받지 않고, 처음 실제 악기 소리를 사용할 때 한 번 받아 런타임 캐시에 저장합니다. GitHub Pages 첫 접속과 PWA 설치의 부담을 줄였습니다.
- `피아노`와 `그랜드 피아노`가 둘 다 같은 Stereo Grand 프리셋이던 중복을 줄여, 일반 피아노는 Bright Grand, 그랜드 피아노는 Stereo Grand로 구분했습니다.
- 전통악기 전용 샘플이 없는 항목은 계속 `근사`로 표시합니다. GeneralUser GS만으로 실제 가야금·대금·해금·장구·고쟁·얼후·비파·타블라·네이·코라 등의 고유 음색을 완전히 재현할 수는 없습니다.

# MARU WORLD MUSIC MAKER V0.17.3 SOUND LEVEL + WORLD MAPPING FIX

V0.17.3은 실제 SoundFont 재생 시 `velocity` 값이 Sfumato 엔진에 전달되지 않아 모든 샘플이 기본값 0.3으로 작게 재생되던 문제를 수정했습니다. 미리듣기는 기본 약 0.72, 조합 반주는 약 0.48을 기준으로 악기군별 레벨을 보정해 작은 현악기·관악기·베이스·패드가 묻히지 않도록 했습니다. 드럼/팀파니처럼 큰 샘플은 과도하게 튀지 않도록 낮췄습니다.

선택 악기가 6개를 넘으면 기존에는 앞의 6개만 실제 반주에 들어가고 나머지는 화면에만 표시되던 문제도 수정했습니다. 이제 최대 6개 레이어를 동시에 유지하면서 선택한 악기를 순환시켜 반주 전체에서 모두 들리게 합니다.

GeneralUser GS에 실제 전통악기 샘플이 없는 경우의 근사 매핑도 다시 조정했습니다. 반수리는 리코더 대신 플루트 계열, 탄푸라는 신스 스트링 대신 시타르 계열, 네이는 오카리나 대신 숨결이 강한 플루트 계열, 코라는 스틸 기타 대신 하프 계열로 변경했습니다. 장구는 스네어 중심 소리를 제거하고 톰 계열 양면북 느낌으로, 타블라·다르부카·젬베·봄보는 서로 다른 GM 타격키 조합으로 분리했습니다. 정확한 전통악기 샘플이 없는 항목은 계속 `근사`라고 표시합니다.

# MARU WORLD MUSIC MAKER V0.17.1 WORLD SAMPLE MAPPING FIX

V0.17.1은 악기별 샘플 매핑을 다시 점검해 같은 소리로 들리던 악기를 더 세분화했습니다. 팀파니는 GeneralUser GS의 실제 `Timpani` 프리셋으로 수정했고, 샤쿠하치는 실제 `Shakuhachi`, 발라폰은 마림바 계열, 고토·가야금·고쟁은 서로 다른 현악 계열 프리셋을 사용하도록 분리했습니다. 장구·타블라·다르부카·젬베·봄보·드럼 세트는 악기별 타격음 순서를 따로 두어 미리듣기와 반주에서 같은 한 음만 반복하지 않습니다. 정확한 전통악기 샘플이 SoundFont에 없는 경우에는 카드에 `근사`라고 표시합니다.

V0.17.0은 30MB GeneralUser GS SoundFont의 실제 녹음 샘플을 사용합니다. 피아노·기타·베이스·드럼·현악기·관악기와 고토·샤미센·시타르·칼림바·타이코 등의 소리가 실제 샘플로 분리됩니다. 공개 음원에 정확한 한국 전통악기가 없는 경우 고토·플루트·피들·타악기 샘플로 근사하고, 앱의 악기 카드에 이를 표시합니다. 샘플을 불러오지 못할 때만 V0.16 표현 합성 엔진으로 자동 전환합니다.

포함 라이선스: `samples/GENERALUSER-LICENSE.txt`, `vendor/SFUMATO-LICENSE.txt`, `vendor/SOUNDFONT2-ESM-LICENSE.txt`, `vendor/VEXFLOW-LICENSE.txt`.

V0.12.3은 악보를 열면 기본적으로 한 줄의 4마디가 화면 폭 안에 모두 보이도록 축소합니다. 좌우 이동 없이 한 줄 전체를 확인하며, 필요한 경우에만 `크게 보기`와 `더 크게`를 선택할 수 있습니다.

V0.12.2는 모든 한국어 가사를 특정 예시 단어가 아니라 BPM과 박자에 따라 자동으로 마디 배치합니다. 느린 곡은 `오늘도 / 너를 / 기다려`, 보통 빠르기는 `오늘도 너를 / 기다려`, 빠른 곡은 `오늘도 너를 기다려`처럼 한 마디의 가사 길이가 달라집니다. 띄어 쓴 단어와 조사를 중간에서 강제로 자르지 않으며, 사용자가 직접 입력한 슬래시(`/`)는 수동 마디 경계로 우선 적용합니다. 각 마디 안에서는 온음표부터 64분음표까지 선택해 총박자를 맞춥니다.

V0.12.1은 `지워지지 않는 / 미안한 마음을 / 꿈속에서 / 만나`처럼 슬래시(`/`)로 나눈 네 구절을 각각 한 마디에 배치합니다. 큰 악보 보기를 기본으로 사용하며, 음표를 클릭하면 화면 위에 고정된 편집 막대에서 선택 위치를 계속 확인하면서 반음 올리기·내리기와 해당 마디 재생을 할 수 있습니다. 선택 음표는 진한 분홍색으로 표시됩니다.

V0.12.0은 한국어 가사의 음절 수에 따라 온음표부터 64분음표까지 자동 배분하면서 각 마디의 박자 합계를 정확히 유지합니다. 악보의 마디를 클릭해 시작·끝을 정하고 한 마디부터 여러 마디 또는 전체 곡을 재생·반복·마이크 녹음할 수 있습니다. 음표 하나를 클릭해 반음씩 올리고 내리며 선택 구간의 녹음 목소리를 악보 음정에 맞춘 WAV로 만들 수 있습니다.

## 사용 순서

1. 악보를 만든 뒤 원하는 마디를 클릭합니다.
2. `시작 마디 지정`과 `끝 마디 지정`으로 구간을 정합니다.
3. `선택 마디 듣기` 또는 `선택 구간 녹음`을 사용합니다.
4. 음표를 클릭하면 반음 올리기·내리기, 길이, 세기, 쉼표를 수정할 수 있습니다.

V0.11.3은 가사 한 구절을 한 마디에 몰아넣지 않고 기본 두 마디에 배치합니다. 4/4박자는 한 마디 4박씩 두 마디 8박을 사용하며, 짧은 가사는 음절 사이에 여음을 두고 긴 가사는 두 마디 전체 음표에 나눕니다. 두 마디 중 어느 마디를 선택해도 같은 구절을 함께 수정합니다.

V0.11.2는 작곡 버튼을 누를 때 화면과 내부의 이전 가사·악보 상태를 먼저 초기화합니다. 고정 예시 가사를 불러오지 않고 현재 입력한 이야기, 사용자가 선택한 핵심 단어, 직접 입력한 후렴 문구만으로 가사 후보 3개를 만듭니다. 마지막 후렴도 현재 이야기의 후렴만 변형해 사용합니다.

V0.11.1은 선택한 BPM·박자·목표 길이로 실제 필요한 마디 수를 자동 계산합니다. 1절, 프리코러스, 후렴, 간주, 2절, 두 번째 후렴, 브리지, 마지막 고음 후렴, 아웃트로가 각각 독립된 구간으로 작곡되며 32마디를 되풀이하지 않고 전체 악보를 순서대로 재생합니다.

V0.11.0은 가사 글자 수로 멜로디를 다시 만드는 방식을 중단하고, 구간별 모티프와 저·중·고음 흐름을 먼저 작곡합니다. 한 줄 4마디를 고정하며 가사가 길면 한 음표에 여러 음절을 묶고, 짧으면 여음으로 배치합니다. 전체 가사를 수정해도 기존 멜로디와 박자는 유지되며 마디와 음표를 각각 클릭해 수정할 수 있습니다.

V0.10.6은 이야기 분석 결과에 맞는 자연스러운 가사 후보 3개를 제공하고, 후보 선택 후 전체 가사를 자유롭게 수정하거나 복사·붙여넣을 수 있습니다. 수정 가사를 적용하거나 자동 반영을 켜면 각 마디의 글자 수에 맞춰 음표 수와 길이를 다시 만들고 전체 박자를 유지합니다.

V0.10.5는 입력한 이야기의 단어를 마디 가사로 나누며, 자동 리듬에서 공백을 제외한 가사 글자 수와 음표 수를 1:1로 맞춥니다. 4글자는 4음표, 6글자는 6음표가 되면서도 한 마디의 전체 박자는 정확히 유지합니다. 전체 가사·악보 가사·저장 데이터는 같은 원본을 사용합니다.

V0.10.4는 한 줄 4마디 구조를 유지하면서 오선과 음표를 크게 그리고, 마디 번호·구간 이름·마디 전체 가사·음세기를 분리해 읽기 쉽게 표시합니다. 화면 맞춤·크게 보기·더 크게 보기 버튼도 추가했습니다.

V0.10.3은 마디에서 고치거나 지운 가사를 전체 가사에 즉시 동기화합니다. 불러온 저장곡은 새 항목을 만들지 않고 같은 곡에 덮어쓰며, 남아 있는 예전 저장곡을 한 번에 지우는 버튼도 추가했습니다.

V0.10.1은 한 줄의 4마디 사이 여백을 제거해 오선 5줄이 끊김 없이 이어지고, 세로 마디선으로만 구분되는 일반 가요 악보 형태로 개선했습니다.

V0.10.0은 작곡가의 작업 순서처럼 장르·BPM·박자·조성을 바탕으로 멜로디를 먼저 만든 후, 음표 수에 맞는 짧고 반복적인 가사를 배치합니다. 악보는 한 줄 4마디 × 8줄, 총 32마디로 고정되며 2절은 1절 멜로디를, 반복 후렴은 첫 후렴 멜로디를 그대로 사용합니다. 재생 시 선택 길이까지 반복 편곡합니다.

V0.9.4는 브라우저 저장 시 원본 가사뿐 아니라 마디별 가사 수정, 개별 음표의 높이·길이·음세기·쉼표, 수동 조성·박자 설정을 함께 저장하고 복원합니다.

V0.9.3은 한글 한 음절을 해당 음표 바로 아래에 배치합니다. 쉼표는 가사를 소비하지 않고, 한 음절을 여러 음표로 부를 때는 `－`로 음 끌기를 표시합니다.

V0.9.2는 일반 가요 악보처럼 한 줄에 4마디를 이어서 배치합니다. 모바일에서는 악보를 좌우로 움직여 크게 볼 수 있습니다.

V0.9.1은 모든 마디에 번호와 굵은 시작·끝 구분선을 표시해 마디 경계를 바로 알아볼 수 있게 개선했습니다.

V0.9.0은 오선악보의 음표를 하나씩 클릭해 음높이·길이·음세기·쉼표를 수정하고, 마이크 목소리의 음정을 분석해 악보 음정에 맞춘 시험용 보정 WAV를 만드는 기능을 추가했습니다.

음악 이론을 몰라도 분위기, 지역, 악기를 골라 가사와 음악 설계를 만들 수 있는 설치형 웹앱(PWA)입니다.

### V0.20.0 최종 보강 (박자·보컬 참조·컴팩트 악보)
- 4/4뿐 아니라 3/4·6/8 후보를 분석 피드백 카드에서 바로 비교/확정할 수 있습니다. 박자 변경 시 비트 시작점·멜로디·코드·악보·편곡을 함께 다시 계산합니다.
- 3/4 자동 채보에서 4박으로 계산하던 경로를 제거하고, 분석/코드/멜로디/원곡 동기화가 같은 마디 길이를 사용합니다.
- `녹음 음성 같이 듣기`는 디코딩된 원곡 버퍼를 편곡과 동기화하고, 보컬 또렷 모드에서 저역을 정리하고 약 2.5kHz 존재감을 소폭 보강합니다. 보컬 stem 분리는 아닙니다.
- 자동 음량 균형은 피아노/기타/베이스/드럼/현악/패드 역할별 게인을 낮춰 특정 악기가 튀는 현상을 줄입니다.
- 자동 채보 악보는 기본 4마디 폭 약 940px, 시스템 높이 116px로 축소하고, 세부 편집 도구는 기본 숨김 처리합니다.
- 정답 패턴 합성 테스트: 100 BPM 4/4→4/4, 100 BPM 3/4→3/4, 90 BPM 6/8→6/8로 분류. 기존 96 BPM G Major 테스트 음원은 96 BPM / 4/4 / G Major 유지.


## V0.20.1 원곡 음량 수정
- 원곡 단독 듣기는 편곡 속 원음 슬라이더와 분리해 100% 기준으로 재생합니다.
- 마이크 녹음 레벨이 낮으면 RMS/peak를 기준으로 최대 2.5배 범위에서 자동 증폭하며 리미터로 과출력을 억제합니다.
- 전체 편곡에 섞이는 원음은 기본 50%, 20~100% 범위에서 따로 조절합니다.
- 원곡 단독 재생과 편곡 속 원음 음량이 서로 영향을 주지 않게 분리했습니다.


## V0.20.3 실시간 음향 믹서·12밴드 EQ
- 반주와 원곡·보컬을 별도 채널로 선택해 80/160/400/1000/2500/6300/12000 Hz를 -12~+12 dB 조절합니다.
- 채널 출력 0~150%, 평탄/보컬 선명/저음 정리/따뜻하게/라이브 프리셋을 제공합니다.
- 반주 EQ는 SoundFont/합성 악기 버스에 실시간 적용되고, 원곡·보컬 EQ는 분석된 녹음 버퍼의 원곡 단독 재생과 전체 편곡 참고 재생에 적용됩니다.
- EQ 상태는 localStorage에 저장됩니다.


### V0.20.3 12밴드 최종 확장
- 반주와 원곡·보컬 참고를 각각 독립 EQ 채널로 분리.
- 12개 중심 주파수: 60 / 100 / 160 / 250 / 400 / 630 / 1k / 1.6k / 2.5k / 4k / 6.3k / 12kHz.
- 각 밴드 -12~+12dB, 채널 출력 0~150%.
- 평탄 / 보컬 선명 / 반주 뒤로 / 저음 정리 / 따뜻하게 / 라이브 프리셋.
- ‘반주 뒤로’는 반주 채널을 72%로 낮추고 보컬 존재감 대역을 정리해 전체 편곡에서 목소리가 앞으로 오도록 동시 적용.
- EQ 설정은 `maru_mixer_eq_v2`로 저장해 이전 7밴드 설정과 충돌하지 않음.
