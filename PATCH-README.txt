MARU V0.22.98 — 원터치 방송

새 기능
- 큰 “🚀 원터치 방송 시작” 버튼 추가.
- 한 번 클릭하면 다음 순서가 자동 실행됩니다.
  1. MARU_OBS_LIVE 방송창 열기/앞으로 가져오기
  2. PC Helper 상태 확인
  3. OBS 실행 및 WebSocket 연결
  4. MARU LIVE 장면/윈도우 캡처 준비
  5. OBS 송출 시작
  6. 현재 PC/USB 방송목록 확인
  7. 첫 원곡 자동 재생
- 하단 고정 “원곡 시작” 버튼도 “🚀 원터치 방송”으로 변경.
- “■ 전체 방송 종료” 한 번으로 원곡 + OBS 송출 종료.
- 기존 V0.22.96 USB 실시간 원곡/RAM 방송과 V0.22.97 PC 설치 우회 기능 유지.

중요
- 브라우저는 Windows 프로그램을 직접 실행할 수 없으므로 Helper는 항상 켜져 있어야 합니다.
- 새 Helper 패키지의 “1-원터치-준비설정.bat”를 최초 한 번 실행하면 Windows 로그인 때 Helper가 자동 실행되도록 등록됩니다.
- 이후에는 MARU의 “🚀 원터치 방송 시작” 버튼 하나만 누르면 됩니다.
- OBS의 BIGO 송출 연결 정보는 OBS에 미리 설정되어 있어야 실제 BIGO LIVE가 시작됩니다.
