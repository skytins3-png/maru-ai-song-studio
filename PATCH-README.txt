MARU MUSIC LIVE V0.22.75 — AI 사전 자막 생성

기준 파일: github-pages (2)(4).zip / V0.22.74

핵심 변경
- 22.74의 재생 중 captureStream + SpeechRecognition 방식 폐기
- 방송 재생 중 자막 생성/음성인식/오디오 캡처를 하지 않음
- 가사가 없는 새 음원을 방송목록에 등록하면 1곡씩 사전 분석
- 브라우저 안에서 Whisper tiny 다국어 모델을 사용해 음원 파일 자체를 문자로 변환
- 생성 결과를 곡별 자막으로 저장하여 방송 때는 V0.22.73처럼 저장 자막만 표시
- 방송 시작/재개 시 백그라운드 AI 자막 분석을 즉시 종료하여 재생 보호
- 자막 관리에 “🤖 음원에서 AI 자동생성” 버튼 추가

첫 실행
- AI 자막 모델은 ZIP에 포함하지 않습니다. 첫 자동생성 때 인터넷에서 모델을 내려받아 브라우저 캐시에 저장합니다.
- 첫 실행은 모델 다운로드 때문에 시간이 걸릴 수 있습니다. 이후에는 캐시를 재사용합니다.

적용 파일
- app.js

테스트 포인트
1. 가사 없는 음원 새로 추가 → AI 자막 모델 준비/분석 상태 표시
2. 자막 관리 → 해당 곡 “자막 있음” 확인
3. 방송 시작 → AI 분석이 중단되고 저장 자막만 재생
4. 방송 중 마이크/실시간 SpeechRecognition/captureStream 자막은 사용하지 않음
