MARU V0.23.01 — USB 완전 자동 연결(ADB Reverse)

없앤 것:
- USB 테더링
- USB 파일 전송 모드
- QR 촬영
- PC 주소 입력
- 매번 USB 설정 변경

처음 한 번만:
1. PC Helper 폴더에서 1-ONE-TOUCH-SETUP.bat 실행
   - Google 공식 Android Platform Tools를 자동 다운로드/설치
   - Helper + USB 자동 브리지 Windows 자동실행 등록
2. Android 보안상 휴대폰에서 USB 디버깅을 켜고
   “이 컴퓨터의 USB 디버깅을 허용할까요?” 창에서 허용을 한 번 누름

그 이후:
- 데이터 지원 USB 케이블만 꽂기
- 휴대폰 MARU 자동 연결
- PC MARU에서 🚀 원터치 방송
- OBS/커버/영상/원곡 오디오 자동

중요:
Android 보안 때문에 ‘USB 디버깅 허용’ 최초 1회 승인은 프로그램이 대신 누를 수 없습니다.
충전 전용 케이블은 데이터 통신 자체가 없어 사용할 수 없습니다.
