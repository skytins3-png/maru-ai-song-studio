MARU MUSIC LIVE V0.22.76 방송 화면 복구 수정

기준: V0.22.73 안정 재생판

수정
1. V0.22.74 실시간 음원 인식 코드를 완전히 제거하고 22.73 재생 구조로 복귀.
2. 가사 없는 곡은 방송 전에 Whisper AI로 사전 자막 생성. 방송 중에는 마이크/음원 분석을 절대 시작하지 않음.
3. 기본 시청자 문구와 곡 사이 내 멘트/다음곡 안내가 시청자 화면에 실제 자막으로 표시되도록 수정.
4. 곡별 영상 -> 기본 영상 전환 시 이전 프레임을 잠깐 유지해 검은 화면 플래시를 줄임.
5. 곡 제목을 화면 하단에 크게 표시. 하단 자막은 제목 위로 올려 겹치지 않게 수정.
6. 캐시 버전 0.22.76으로 갱신.

적용 파일: app.js, index.html, styles.css, sw.js
