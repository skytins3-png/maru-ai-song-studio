MARU MUSIC LIVE V0.22.77 — 미니 화면 축소 시 상단 고정 / 하단 잘림 수정

기준: V0.22.76 방송 화면 복구 수정판

이번 수정
1. 시청자 미니/PWA 화면을 세로로 축소할 때 이미지·영상의 위쪽(얼굴/머리)이 잘리지 않도록 상단을 기준점으로 고정했습니다.
2. 화면 비율 때문에 cover 잘림이 필요한 경우 아래쪽부터 잘리도록 object-position을 center top으로 변경했습니다.
3. 일반 시청자 화면, BIGO floating 모드, 댓글/축소 모드에 동일 규칙을 최종 우선순위로 적용했습니다.
4. 이미지와 영상 모두 같은 동작을 하도록 적용했습니다.
5. 캐시/리소스 버전을 0.22.77로 올려 기존 CSS가 남지 않도록 했습니다.

유지
- V0.22.76의 재생/자막/안내/곡별 영상·커버 구조는 변경하지 않았습니다.
- object-fit: cover는 유지합니다. 따라서 좌우 빈 공간 없이 꽉 채우는 방식은 그대로입니다.
