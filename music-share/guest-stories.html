시청자 사연 보내기

별명과 사연만으로 신청할 수 있도록 준비한 화면이야. 시청자는 GitHub 계정이 필요 없어. 자료는 공개 게시판이 아닌 비공개 접수 서버로 보내고, 형의 승인을 받기 전에는 절대 방송에 사용하지 않아.

비공개 접수 서버 연결 여부 확인 중…

1개, 최대 8MB. 비공개 격리 보관하며 보안 검사·권리 확인 전에는 공개·재생되지 않습니다. 긴 영상/대용량 음악은 별도 업로드 기능이 필요합니다.

접수 서버가 연결되기 전에는 사연을 전송하지 않습니다.

현재 임시 GitHub 공개 접수 방식

비공개 접수 서버가 준비되기 전에는 기존 GitHub 공개 접수만 작동합니다. 이 방법은 GitHub 로그인과 공개 게시가 필요하므로 개인정보나 비공개 파일을 올리면 안 됩니다.
