MARU 라디오 이용 방법

환영합니다! 아환의 음악과 토크를 듣고, 이야기나 희망곡을 신청해 보세요. 휴대폰에서도 이용할 수 있습니다. 듣기에는 GitHub 로그인이 필요 없지만 사연·신청서를 보내려면 GitHub 로그인이 필요합니다.

① 음악과 토크 듣기

  1. 라디오 듣기를 누르세요.
  2. ▶ Start radio를 누르면 아환과 동료 진행자의 영어 토크 미리듣기가 시작됩니다.
  3. 음악이 등록되어 있으면 승인된 원곡도 재생됩니다. 다음 곡은 Next song, 종료는 Stop입니다.
  4. 공개 음악은 음악 목록에서 검색하고, 창작자가 공개 다운로드를 허용한 곡만 내려받을 수 있습니다.

웹 미리듣기입니다. 화면 잠금이나 다른 앱으로 이동하면 소리가 멈출 수 있으며, BIGO LIVE로 자동 송출되지는 않습니다.

▶ 라디오 듣기

② 사연 보내기 · 희망 방송 시간

  1. 사연 보내기 페이지를 열어 주세요.
  2. 방송용 별명, 제목, 사연(20~1,200자)을 입력합니다.
  3. 원하면 희망 방송 시각을 한국시간(KST)으로 선택하세요. 선택하지 않아도 신청할 수 있습니다.
  4. 공개 및 방송 낭독 동의에 체크하고 Continue to public story submission을 누릅니다.
  5. 열리는 GitHub 화면에 로그인한 뒤 Submit new issue를 눌러야 실제 접수됩니다.

중요: 사연은 GitHub에 즉시 공개됩니다. 전화번호, 주소, 계좌, 비밀번호, 개인 신원, 사적인 내용은 절대 적지 마세요. 안전 검사 후 방송 제작자가 승인한 사연만 후보가 됩니다. 희망 시간은 확정 예약이 아닙니다. 현재 웹 라디오가 재생 중일 때, 승인된 사연을 요청 시각 이후 최대 30분 이내의 토크 구간에 반영할 수 있습니다. 정확한 송출을 보장하지 않습니다.

사연 작성하기

③ 신청곡 보내기

  1. 신청곡 페이지를 엽니다.
  2. 공개된 원곡 목록에서 원하는 노래를 선택합니다.
  3. 공개 신청에 동의한 뒤 GitHub에서 로그인하고 최종 제출합니다.
  4. 라디오가 재생 중일 때 신청된 공개곡을 우선 선택할 수 있습니다. 정확한 재생 시간은 보장되지 않습니다.

목록에 없는 외부 곡은 자동 다운로드하거나 즉시 재생하지 않습니다. 그런 곡은 아래 미디어 검토 신청을 이용하세요.

신청곡 고르기

④ 사진 · 영상 · 내 노래 · 외부 노래 신청

  1. 미디어 방송 신청을 열어 주세요.
  2. 사진, 영상, 본인 창작곡, 외부 곡 가운데 유형을 선택합니다.
  3. 제목, 제작자·아티스트, 소개할 이야기, 권리 상태와 희망 시간을 입력합니다.
  4. 공개 게시 및 권리 확인 관련 동의에 체크하고 GitHub에서 최종 제출합니다.

현재는 신청 내용만 접수합니다. 실제 사진·영상·음악 파일을 보내는 기능은 아직 없으며, 청취자 파일에 대한 실시간 백신 검사도 이루어지지 않습니다. 외부 음악은 방송 권한이 별도로 확인되기 전에는 재생할 수 없습니다. GitHub 이슈에 파일이나 외부 링크를 붙이지 마세요.

미디어 검토 신청

자주 묻는 질문

방송 시간만 고르면 자동으로 들려주나요?

아닙니다. 희망 시간은 신청입니다. 안전 검사와 제작자 승인 후, 웹 라디오가 실제로 작동하고 있을 때만 반영됩니다. BIGO의 예약 자동 송출은 아직 지원하지 않습니다.

제출을 눌렀는데 사연이 안 보여요.

입력 페이지에서 이동한 뒤 GitHub의 Submit new issue까지 눌렀는지 확인하세요. GitHub 계정이 필요하며, 내용 검토 전에는 방송에 나오지 않습니다.

사용자 사진·영상·음악도 바로 올릴 수 있나요?

아직은 아닙니다. 지금은 작품 소개와 권리 상태만 신청할 수 있습니다. 실제 파일 수신과 악성코드 검사, 저작권·초상권 검증은 별도의 안전한 서버가 준비되어야 합니다.

사연을 취소하거나 수정하고 싶어요.

직접 제출한 공개 GitHub Issue에서 내용 수정 또는 닫기를 할 수 있습니다. 수정된 사연은 다시 검토와 승인 절차를 거쳐야 합니다. 이미 공개된 정보의 복사본까지 회수되지는 않을 수 있습니다.

English · Listener instructions

Listen: Open MARU RADIO and tap Start radio. No GitHub login is needed to listen.

Stories: Open Send a story, enter a nickname, title, story, and optional requested Korea time (KST). Check both public-posting and radio-reading permissions. Sign in to GitHub and press Submit new issue. Your story is immediately public and will be considered only after screening and producer approval. A requested airtime is not a confirmed schedule.

Music requests: Choose a publicly available original from Request a song; sign in to GitHub to complete submission.

Photos, videos, or outside music: Use Media review request to submit only the proposal details. Actual files cannot be uploaded here yet. Never submit private information, file attachments, or links. Copyright clearance and live BIGO broadcasting are not automatic.

中文 · 听众使用说明

收听：打开 MARU 电台，点击 Start radio 即可试听，不需要 GitHub 登录。

投稿故事：进入 故事投稿，填写昵称、标题、故事；可以选择希望播出的韩国时间（KST）。勾选公开发布和播出授权后，登录 GitHub 并点击 Submit new issue 才算正式提交。投稿内容会公开，必须通过安全检查及主持人审核。希望时间不等于确定播出时间。

点歌：在 点歌页面选择已公开的原创歌曲，并通过 GitHub 完成提交。

图片、视频、其他歌曲：通过 媒体审核申请填写作品资料。现在不能直接上传文件，也不会自动播放未经版权确认的作品。不要提交个人隐私、附件或外部链接。

MARU RADIO · 사용자 신청은 승인 전 방송되지 않습니다. 문의·신청은 공개 GitHub 절차로 운영되므로 개인정보를 제출하지 마세요.
